# Twinspire Web
Build a website using Twinspire Web void of any HTML5, CSS3 or even server side languages.

Haxe, an open source programming language, let's us target both the client and server using a single source, and Twinspire Web takes full advantage of this.

We use Kha and the Core Twinspire library to help you build interactive, intuitive websites using any design format of your choosing, with all the necessary tools. Use dynamic platform independent routing with either the `History` API or a Hash-based URL router.

On the server, target any language Haxe supports, including PHP, JavaScript and Python, and connect your client to a server database.

## Why Twinspire Web?
Twinspire is built for programmers, not website designers. It is built for ease of use, not complicated hierarchies and confusing CSS which sometimes works and other times not. It is built for simple, fast performance without standard advertisement injections, which both avoids ad blockers and ensures adverts run smoothly (because it is not injected, you control how adverts are displayed and not the advertiser).

Twinspire is NOT a replacement for the current Web standards. It is especially NOT designed for web designers, as it is designed to put the programmer first. We build on top of the concept of IMGUI (immediate mode graphical user interface) to speed up design and development of websites using JavaScript as the language that powers the website.

## Features
While this project is a work-in-progress, think of the following features as a roadmap.

 * Markdown-based text and paragraph parsing and rendering.
 * Platform independent router.
 * Macro-based client-to-server communication (with AJAX/Database calls handled automatically).
 * RESTful APIs generated into usable functions that return their respective JSON objects.
 * Macro-based CMS generation for any type of database object, including a login system, user management, data imports/exports, and search filtering.
 * Automatic Layout changing for mobile and desktop views.
 * Everyday web components such as tables, grids, menus, navigation, sections, etc.
 * Templates for blogging, forums, image galleries, ecommerce, etc.
 * And probably more...

Yes, it sounds like a lot. But we are just getting started.
